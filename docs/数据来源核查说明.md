# 肺癌数据集来源核查

核查日期为2026年10月3日。

## 已找到的匹配副本

- Kaggle 页面 [Lung Cancer Prediction Dataset](https://www.kaggle.com/datasets/adnananalytics/lung-cancer-prediction-dataset)
- 上传者 Adnan Hyder，账号 adnananalytics。
- 文件名 lung_cancer_dataset.csv，版本1。
- 页面显示的更新时间为2025年3月31日。
- 下载的原始文件保存在同目录的 `Kaggle_lung_cancer_dataset_original.csv`。

本次从 Kaggle 公开下载接口取得文件，随后与论文目录中的 `Lung Cancer Dataset.csv` 逐行比较。

| 核查项目 | 结果 |
|---|---|
| 行数 | 两份均为5,000行 |
| 字段及顺序 | 18个字段完全相同 |
| 行顺序 | 按相同行号比较，全部离散变量和标签对应一致 |
| 标签 | Kaggle为YES/NO，本地为1/0；YES→1、NO→0后全部一致 |
| 类别数量 | YES/1为2,037，NO/0为2,963 |
| 年龄和全部二值变量 | 所有行完全一致 |
| ENERGY_LEVEL | 2个数值存在小数差异，最大绝对差约4.02×10⁻⁹ |
| OXYGEN_SATURATION | 10个数值存在小数差异，最大绝对差约4.94×10⁻⁹ |

逐项差异保存在 `小数差异记录.json`。该结果表明已找到与本地分析文件高度对应的公开副本。由于标签编码和12个连续数值的小数差异，两份文件不应描述为未经处理的完全一致文件。此核查不能确定用户最初从哪个账号下载。

## 旧地址与原始来源

用户最初提供的 `mysarahmadbhat/lung-cancer` 经下载核查为309条记录、15项输入、标签LUNG_CANCER，与本地文件不同。

两篇使用5,000条及相应字段的公开研究指向旧地址 `shantanugarg274/lung-cancer-prediction-dataset`。本次直接访问该 Kaggle 页面显示“We can't find that page”，下载接口返回403。这可以解释旧链接难以找回，但尚无法确定页面不可访问的原因。

本次找到的 adnananalytics 页面没有数据描述，License 显示 Unknown。页面尚未提供采集机构、真实或合成性质、标签诊断依据或与旧地址的关联说明。

## 对论文的影响

该副本解决了相应数据的公开访问及文件匹配问题，可在论文的数据可得性说明中作为当前可访问地址，并准确记录访问日期、文件名和版本。作者应确认它与实际使用的数据的关系。

数据真实来源和标签含义仍需另行溯源。页面题名“Lung Cancer Prediction Dataset”本身不足以证明所有记录为确诊肺癌患者。当前也未确认可公开再分发的许可，因此将文件存入持久仓库前应核实授权依据。
