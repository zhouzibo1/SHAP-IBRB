## 一、数据说明候选表述

### 数据组成与可访问副本

本研究使用包含 5000 条记录的公开表格基准，包含 17 个输入变量和目标字段 PULMONARY_DISEASE。分析文件中标签编码为 1 和 0，对应 2037 条阳性记录与 2963 条阴性记录。当前可访问的 Kaggle 副本位于 adnananalytics/lung-cancer-prediction-dataset，其 YES/NO 标签与分析文件的 1/0 编码逐行对应。进一步核对 MatSci-ML Studio 公开仓库中的 case2.csv，全部记录顺序、年龄、二值变量与标签均对应；两项连续变量在保留 8 位小数后完全对应。

Kaggle 地址：https://www.kaggle.com/datasets/adnananalytics/lung-cancer-prediction-dataset

公开文件：https://github.com/wy314159-lyq/MatSci-ML-Studio1/blob/main/case2.csv

### 标签解释的文献依据

Lam 等在使用具有相同目标字段、相近数据结构及类别比例的 Kaggle 数据开展预测研究时，将 PULMONARY_DISEASE 解释为肺癌有无的二分类指标。该文为采用这一肺癌预测任务解释提供了文献先例。

参考文献：Lam 等，Improving Lung Cancer Prediction Using Advanced Hyperparameter Optimization and Nested Cross-Validation，Engineering Reports，2025，7(11)，e70486，DOI 10.1002/eng2.70486。

位置：第 3.1 节第一段。完整引用及原句见同目录“明确肺癌标签解释文献补充.md”。

https://onlinelibrary.wiley.com/doi/full/10.1002/eng2.70486

采用决定：按用户要求，将 Lam 等论文纳入本研究 PULMONARY_DISEASE 的肺癌标签解释依据，暂仅记录，未修改论文。

拟采用表述：

“本研究沿用 Lam 等对 PULMONARY_DISEASE 的文献解释，将该字段作为肺癌有无的二元目标，以文件提供的既有标签开展分类评价（1 为阳性，0 为阴性）。”

英文候选表述：

“Following the interpretation reported by Lam et al., we treat PULMONARY_DISEASE as a binary lung cancer target and evaluate classification using the dataset-provided labels (1: positive; 0: negative).”

该引用的证据用途为标签含义的文献解释。原始记录的诊断标准、标签赋值过程和数据真实或合成性质仍按来源核查记录分别处理。

## 二、MatSci 文件实核结果

对应论文：MatSci-ML Studio: an interactive workflow toolkit for automated machine learning in materials science，Journal of Materials Informatics，2025，5，51，DOI 10.20517/jmi.2025.45。

https://www.oaepublish.com/articles/jmi.2025.45

该论文 Case 2 为肺癌预测任务。数据与材料可得性部分明确指向上述 GitHub 仓库；参考文献 27 指向 shantanugarg274 的旧 Kaggle 地址。

下载地址：https://raw.githubusercontent.com/wy314159-lyq/MatSci-ML-Studio1/main/case2.csv

下载文件：MatSci_case2.csv。核对程序：核对MatSci公开数据.py。详细结果：MatSci数据逐行比较.json。

| 项目 | 与本地分析文件的比较结果 |
|---|---|
| 记录数、字段数及字段顺序 | 5000 行、18 列，字段顺序相同 |
| 行顺序下的年龄、全部二值变量、标签 | 全部相同 |
| 标签数量 | 1：2037；0：2963 |
| ENERGY_LEVEL | 4998 个数值存在精度差，最大绝对差约 4.99968×10⁻⁹ |
| OXYGEN_SATURATION | 4990 个数值存在精度差，最大绝对差约 4.99963×10⁻⁹ |
| 本地两项连续变量保留 8 位小数 | 全部等于 case2.csv 对应数值 |

与此前下载的 Kaggle 副本比较：字段、行数、年龄、二值变量及映射后的标签也全部对应；两项连续变量分别均有 5000 处精度差，保留 8 位小数后全部对应。

结论：已找到与本地分析文件逐行对应、连续变量精度不同的公开文献配套副本。该结果加强了数据版本和既有应用的可追溯性。实际下载来自当前 main 分支，不据此推断该文件在论文发表时的具体版本。
