# 返修实验采用总方案

2026年10月7日。作者内部采用与写作安排。系统决定为Major Revision，三位审稿人的原文依据为《审稿意见.pdf》及其提取文本。本轮整理全部已保存实验/分析结论；其中含合并报告、重复核验及早期分支，目录条目数与独立实验次数分别计数。原稿尚未修改，本文安排的是返修采用材料及后续落稿顺序。

## 建议的论文证据主线

以“规则规模可控、区间布局有贡献、推理可追踪、在独立肺癌结局任务上具有竞争力”为中心组织结果。最有利且较完整的证据来自受控组件比较及NLST确认；传统等宽IBRB为架构参照，原稿全部机器学习基线继续保留，用于交代预测表现的位置。

正文优先呈现主问题与关键结果，补充材料承载全部对照、指标、重复和统计区间。正式采用的对照中，保留性能强的竞争方法及同任务的不利结果，让复杂度与预测表现的权衡成为论证的一部分。早期搜索和未采用分支保留为内部开发记录；与原稿数值直接相关的核查在逐点回复中准确回应。

## 可直接使用的结果叙述草稿

“在原基准的受控1000条训练预算下，所提出流程获得88.15%的平均准确率、0.91490的AUC及0.10173的Brier，相对传统等宽IBRB的平均Brier降低8.26%。固定设置组件对照表明，在逐属性规则数量一致时，监督区间布局取得较低平均误差；SHAP筛选将平均规则数由88.0减至33.8，在较小规则库下维持接近的预测表现。在NLST患者级确认队列中，模型获得0.85310的AUC、0.03040的Brier及0.33517的AP。这些结果支持结构规模与预测表现之间的实用权衡，并提供独立肺癌结局任务上的方法评价证据。”
