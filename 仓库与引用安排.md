# Repository and citation arrangements

The GitHub repository will host the project code and permitted reproducibility files. A fixed paper-linked version can be archived at Zenodo. Add the actual repository URL and version DOI to README.md, CITATION.cff, release metadata, the manuscript availability statement and the reviewer responses after creation.

Author names and affiliations follow AUTHORS.md. Code uses MIT; author-created research outputs use CC BY 4.0; NLST source attribution and changes are in THIRD_PARTY_NOTICES.md. Original-benchmark redistribution scope remains unresolved and must be settled for any public inclusion of third-party input records. Acquisition scripts provide the documented source route.

Final figure/table labels will be matched to the revised manuscript. See 发布待落实字段.csv for the remaining publication fields.
